# Scientific Limitations

- The verified Bengaluru comparison contains two NISAR L2-GCOV observations.
- HH/HV differences are measured RTC gamma-zero backscatter changes.
- Robust candidate screens are distribution-based and are not calibrated
  event detectors.
- Speckle, soil moisture, vegetation structure, temporary water, geometry,
  incidence angle, and processing effects can all contribute to differences.
- No contemporaneous optical, rainfall, soil-moisture, land-cover, OSM, or
  field dataset is currently verified for the case study.
- Candidate pixels and polygons must not be labelled as confirmed flooding,
  construction, urban growth, deforestation, or damage.
- Event-level precision, recall, F1, IoU, and confusion matrices require
  independently verified reference labels. Existing prototype benchmark scores
  are not independent validation of the real NISAR case study.
